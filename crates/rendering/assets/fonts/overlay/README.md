# Overlay fonts

The key-press overlay draws each keyboard's keys in a typeface that fits it,
and captions can be set in Inter. These fonts are embedded in the renderer so
exports look the same on every platform.

| File | Font | Licence | Notes |
| --- | --- | --- | --- |
| `Inter-Medium-Keycaps.ttf` | Inter 4, weight 500, renamed "Inter Keycaps" | SIL OFL 1.1 (`Inter-OFL.txt`) | A static instance of the variable font, subset to Latin, punctuation, arrows and keyboard symbols. Inter has no Reserved Font Name. |
| `Inter-SemiBold-Captions.ttf` | Inter 4, weight 600, optical size 28 | SIL OFL 1.1 (`Inter-OFL.txt`) | A static instance of the variable font, subset to Latin, Latin Extended, Vietnamese, Greek, Cyrillic, punctuation, currency and arrows. Other scripts fall back to system fonts. |
| `Selawik-Regular.ttf` | Selawik 1.01 | SIL OFL 1.1 (`Selawik-OFL.txt`) | Unmodified. |
| `Ubuntu-Medium.ttf` | Ubuntu Medium | Ubuntu Font Licence 1.0 (`Ubuntu-UFL.txt`) | Unmodified. |
| `IBMPlexSans-Medium.ttf` | IBM Plex Sans Medium | SIL OFL 1.1 (`IBMPlexSans-OFL.txt`) | Unmodified. |
