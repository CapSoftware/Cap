Cap links look like Cap now. Every page on cap.so and every share link gets a proper preview card when pasted into chat apps, socials, or docs.

## Features

- **Video preview cards** - Share links unfurl with the video's title and thumbnail instead of a generic image.
- **Copy as rich link** - Copying a share link also carries a formatted title link, so pasting into emails and docs gives a clean clickable preview.
