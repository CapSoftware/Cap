publishedAt: "2026-06-10"

Share a whole collection, not just one video. Any space or folder can now be published to a public page that lists all of its Caps.

## Features

- **One link for many Caps** - Publish a space or folder and anyone with the link sees a browsable grid of its videos.
- **Optional password** - Protect a public collection with a password before anyone can view it.
- **Custom branding** - Add a logo and choose a grid or list layout for the public page.
- **Access controls** - Restrict viewing to specific email domains when the audience should stay internal.
