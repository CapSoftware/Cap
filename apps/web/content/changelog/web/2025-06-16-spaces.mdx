Spaces are shared collections inside your organization. Create a space for a team or project, add the right people, and drop Caps into it for everyone to see.

## Features

- **Create spaces** - Set up as many spaces as you need from the dashboard sidebar.
- **Members** - Add and remove organization members per space, so each space is visible to exactly the right people.
- **Shared libraries** - Caps added to a space show up for every member of that space.
