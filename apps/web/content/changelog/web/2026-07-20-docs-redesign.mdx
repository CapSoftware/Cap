The Cap docs have been redesigned from scratch, with clearer navigation, faster search, and answers on demand.

## Features

- **New design** - A cleaner layout with a proper sidebar, so guides for the desktop app, web, self-hosting, and the API are easy to find.
- **Ask the docs** - Ask a question in plain language and get an answer grounded in the documentation, with links to the pages it came from.
- **Expanded guides** - New documentation for storage setup, team migration, and using Cap with agents.
