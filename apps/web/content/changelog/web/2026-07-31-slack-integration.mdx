publishedAt: "2026-07-31"

Cap links now unfurl in Slack. Connect your Slack workspace from organization settings and shared Caps expand into rich previews your team can watch without leaving the conversation.

## Features

- **Link unfurls** - Pasting a Cap link in Slack shows the title, thumbnail, and an inline player.
- **Simple setup** - Install the integration from organization settings with a standard Slack authorization flow.

## Improvements

- **Playable previews in more apps** - Tools that use Iframely for link previews, such as Notion, now show an inline Cap player for public videos.
