title: Playback Speed Controls
publishedAt: "2026-06-08"
---

Playback speed is now a first-class setting. Viewers get a speed dial on the player, and owners can decide what speed a video starts at.

## Features

- **Speed dial on the player** - Viewers can switch playback speed directly from the share page and embeds.
- **Per-video default** - Set a default playback speed for an individual Cap in its settings.
- **Organization default** - Admins can set a default speed for every video in the organization.

## Improvements

- **Links in comments** - URLs pasted into comments are now clickable.
