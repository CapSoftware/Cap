title: Folder Sorting and List View
publishedAt: "2026-09-03"
---

Folders now sort the way you expect, with a list view for long names and big libraries.

## Features

- **Natural sorting** - Numbered folders order correctly, so `2_Intro` comes before `10_Setup`.
- **Sort control** - Sort folders by name (A to Z or Z to A), or by newest or oldest.
- **Grid and list views** - Switch to a list layout that gives each folder name the full width.
- **Whole-card links** - Click anywhere on a folder card to open it.

## Fixes

- **Truncated folder names** - Names are no longer cut off at a fixed width on wide screens.
