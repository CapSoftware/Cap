Cap Pro customers can ask us to move their Loom library for them. Request a concierge migration from the Loom import page and we import your videos into Cap.

## Features

- **Concierge migration** - Follow the steps on the Loom import page, then track your request from pending to complete.
- **Videos Loom will not serve** - We can import those from an MP4 you provide.
