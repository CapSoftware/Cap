Self-hosting Cap is now a single command. A new Docker Compose setup brings up the full web app, database, and storage in one go, with rewritten self-hosting docs to match.

## Improvements

- **docker compose up** - One command starts everything Cap needs to run on your own infrastructure.
- **Clearer docs** - The self-hosting guide has been rewritten with the new setup, including configuration and upgrade notes.
