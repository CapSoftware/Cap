# Film Looks

Six color looks inspired by film stock. Each one is a starting point: apply it, then fine-tune any slider in the Color tab.

- **Golden Hour**: warm highlights and soft contrast.
- **Night Shoot**: cool shadows with a teal cast.
- **Matte**: lifted blacks and muted color.
- **Noir**: high-contrast black and white.
- **Pop**: clean, punchy and colorful.
- **Super 8**: faded warmth with visible grain.

## Use it

Open a recording in Cap Desktop, go to the Color tab, and pick a look from the Apps row.
