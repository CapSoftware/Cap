# Discord

Share Caps in a Discord channel. Post a single Cap from its menu, or turn on automatic posting so every new Cap lands in the channel as soon as it finishes uploading.

## Set it up

1. In Discord, open the channel's settings, then **Integrations**, **Webhooks**, **New Webhook**.
2. Copy the webhook URL.
3. Install Discord from the Cap App Store and paste the URL.

## What Discord receives

The Cap's title, share link and length. Nothing is sent until you post a Cap or turn on automatic posting.
