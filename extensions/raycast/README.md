# Cap Raycast Extension

Official Raycast extension for [Cap](https://cap.so) — the open-source Loom alternative.

## Features

- **Start Recording:** Trigger a screen recording session instantly via Cap desktop app.
- **Stop Recording:** Stop the active recording session.
- **Open Dashboard:** Quickly access your Cap web dashboard to view and share your recordings.

## Prerequisites

- [Cap Desktop App](https://cap.so) installed and running.
- [Raycast](https://raycast.com) installed on macOS.
