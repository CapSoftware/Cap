# Cap Raycast Extension

Official Raycast extension for [Cap](https://cap.so) — the open-source Loom alternative.

## Commands

- **Start Recording:** Start a recording session using your saved Cap desktop defaults (target, camera, microphone, system audio, and mode), with an optional argument to override Instant or Studio mode.
- **Stop Recording:** Stop the active Cap recording session (automatically copies the shareable video link to the clipboard in Instant mode).
- **Open Dashboard:** Open your Cap web dashboard (respects self-hosted `serverUrl` configured in Cap desktop or Raycast preferences).
- **Open Cap Settings:** Open the Cap desktop settings window.

## Prerequisites

- [Cap Desktop App](https://cap.so/download) installed and running.
- [Raycast](https://raycast.com) installed.
